CUSTOM COMMANDS
Add a phrase pattern and the action it should trigger. Use {version} as a placeholder wherever the spoken Bible version name should be captured.
Behind the scenes each phrase compiles to a matching pattern, e.g.
/^(change|switch|set)\s+(the\s+)?version\s+to\s+(?<version>niv|kjv|nlt|esv|amp)$/i
so "change the version to nlt" and "switch version to NLT" both resolve to the same action.

SEND VERSES TO A LIVESTREAM
NDI Output
Broadcasts the current verse slide as an NDI source on your local network. Add it as an NDI source inside OBS Studio, vMix, or any NDI-compatible switcher, which then encodes and pushes the program feed to YouTube.
  1. Enable NDI Output above.
  2. Open OBS Studio → Sources → Add → NDI Source.
  3. Select "FaithView Pro - Main Display" from the NDI source list.
  4. Start your YouTube stream in OBS as usual — verses appear live.
OBS Browser Source NO PLUG-INS NEEDED
The simplest way to stream to YouTube: OBS captures the FaithView output page directly in a Browser source — no NDI runtime or extra software required. Works on any machine that can reach this server.
  1. In OBS Studio → Sources → Add → Browser.
  2. Paste the URL above; set width 1920, height 1080.
  3. Tick "Refresh browser when scene becomes active".
  4. Start streaming to YouTube — the slide shows through the browser source.
Virtual Camera Output
Exposes the main display as a virtual webcam device selectable in OBS, Zoom, or any app that accepts a camera input. Requires the desktop companion app — coming soon.
Direct Display / Second Screen
Send the main display straight to an HDMI-connected capture card. Requires the desktop companion app — coming soon. Meanwhile, open the Output window (Live display → ↗ Output) fullscreen on the projector/HDMI screen.
