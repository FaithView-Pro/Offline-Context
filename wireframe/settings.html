CUSTOM COMMANDS
Add a phrase pattern and the action it should trigger. Use {version} as a placeholder wherever the spoken Bible version name should be captured.
Behind the scenes each phrase compiles to a matching pattern, e.g.
/^(change|switch|set)\s+(the\s+)?version\s+to\s+(?<version>niv|kjv|nlt|esv|amp)$/i
so "change the version to nlt" and "switch version to NLT" both resolve to the same action.

NDI Output
Broadcasts the current slide as an NDI source on your local network. Add it as an NDI source inside OBS Studio, vMix, or any NDI-compatible switcher, which then encodes and pushes the program feed to YouTube.
  • Enable NDI Output above.
  • Open OBS Studio → Sources → Add → NDI Source.
  • Select "FaithView Pro — Main Display" from the NDI source list.
  • Start your existing YouTube stream in OBS as usual.
    • Virtual Camera Output
    Exposes the main display as a virtual webcam device. Select it as a Video Capture source in OBS, Zoom, or any app that accepts a camera input — useful when NDI isn't available on the network.
    Direct Display / Second Screen
    Send the main display straight to an HDMI-connected capture card, which OBS then reads as a regular Video Capture Device. No network required — best for a wired setup at the switcher.
